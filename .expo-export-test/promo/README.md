# photodumps promo landing (web)

Shareable **8-page** scroll site for social media — not part of the in-app flow.

## Local preview

```bash
npm run serve:promo
```

Open: **http://localhost:3456/promo/**

## Public link (deploy once)

1. Push repo to GitHub.
2. [vercel.com](https://vercel.com) → New Project → import repo (uses root `vercel.json`).
3. Deploy. Your link:

**`https://YOUR-PROJECT.vercel.app/promo/`**

Put that URL in Instagram bio, TikTok, stories, etc.

## Expo in-app route (optional)

`/promo` in the React Native app — for dev only; use the static URL above for the public.
